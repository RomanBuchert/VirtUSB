# Code of Conduct

## Our Goal

VirtUSB aims to provide an open, respectful and technically focused environment
for everyone participating in the project.

We welcome contributors regardless of experience, nationality, gender, age,
religion or other personal characteristics.

## Expected Behaviour

All participants are expected to:

- Be respectful.
- Be constructive.
- Discuss ideas rather than people.
- Assume good intentions.
- Accept that contributors may not be native English speakers.
- Help create a welcoming and productive environment.

Technical disagreements are expected and encouraged when they are expressed
professionally.

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Personal attacks
- Harassment
- Discrimination
- Threats or intimidation
- Trolling or deliberately disruptive behaviour
- Publishing private information without permission
- Offensive or abusive language directed at other people

## Communication

The project language is **English**.

Please focus on the technical meaning of a message rather than its wording.
Many contributors communicate in a language that is not their native language.
If a message appears overly direct, assume that it may simply be the result of
language differences rather than bad intentions.

## Artificial Intelligence

The use of AI tools is explicitly permitted.

Contributors remain responsible for all submitted content, regardless of whether
it was created manually or with AI assistance.

## Enforcement

Project maintainers may edit, remove or reject contributions that violate this
Code of Conduct.

Repeated or severe violations may result in temporary or permanent exclusion
from the project.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub
- Issue discussions
- Pull requests
- Documentation
- Project-related communication channels

## Attribution

This document is inspired by the Contributor Covenant and adapted to the needs
of the VirtUSB project. It is intentionally concise and focuses on practical
collaboration rather than legal language.
